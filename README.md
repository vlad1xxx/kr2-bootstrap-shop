## Описание

Сайт скалодрома «Зацеп» для новичков и опытных скалолазов, разработанный с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap (локально, папка `vendor/bootstrap/`);
- подключение `css/custom.css`;
- шапка страницы и Bootstrap-навигация;
- hero-блок на сетке (`container-fluid` + `container`);
- блок преимуществ;
- сетка залов и популярных абонементов;
- подвал страницы.
