# «Зацеп» — сайт скалодрома на Bootstrap

**Контрольная работа №2**
Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Студент: Сидлецкий Владислав Викторович, группа ЭФБО-05-25.

## Описание

Сайт скалодрома «Зацеп» для новичков и опытных скалолазов, разработанный с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap (локально, папка `vendor/bootstrap/`);
- подключение `css/custom.css`;
- шапка страницы и Bootstrap-навигация;
- hero-блок на сетке (`container-fluid` + `container`);
- блок преимуществ;
- сетка залов и популярных абонементов;
- подвал страницы.

## Практическая работа 10

Тема: «Страница на Bootstrap: компоненты».

Выполнено:

- добавлена единая Bootstrap-навигация с выпадающим меню;
- создана страница каталога абонементов `catalog.html` с фильтром и сортировкой;
- создана страница услуги «Вводное занятие» `product.html`;
- создана страница записи `order.html` с расчётом стоимости;
- использованы компоненты `navbar`, `card`, `btn`, `badge`, `alert`, `modal`, `form-control`, `form-select`, `input-group`, `form-check`, `accordion`, `carousel`, `tabs`, `toast`.
