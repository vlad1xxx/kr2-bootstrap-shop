## Описание

«Зацеп» — сайт скалодрома для новичков и опытных скалолазов. На сайте можно:

- узнать о залах и свежих трассах (с фильтром по залу и уровню);
- выбрать абонемент или разовое посещение в каталоге с фильтрами и сортировкой;
- узнать о вводном занятии для новичков (инструктаж, снаряжение, первые трассы);
- записаться на тренировку или забронировать посещение через форму с расчётом стоимости;
- выбрать детскую секцию, программу дня рождения или зарегистрироваться на соревнования.

Каталог услуг соответствует «каталогу товаров» из методических указаний, вводное занятие — «странице товара», запись — «форме заявки».

## Используемый фреймворк

Bootstrap 5.3.8 и Bootstrap Icons 1.11.3.

## Способ подключения

Bootstrap подключён **локально, без CDN**. Файлы фреймворка лежат в папке `vendor/`:

- `vendor/bootstrap/css/bootstrap.min.css`;
- `vendor/bootstrap/js/bootstrap.bundle.min.js`;
- `vendor/bootstrap-icons/bootstrap-icons.min.css` и шрифты иконок.

Порядок подключения на каждой странице:

```html
<link rel="stylesheet" href="vendor/bootstrap/css/bootstrap.min.css">
<link rel="stylesheet" href="vendor/bootstrap-icons/bootstrap-icons.min.css">
<link rel="stylesheet" href="css/custom.css">   <!-- после Bootstrap, чтобы переопределять стили -->
...
<script src="vendor/bootstrap/js/bootstrap.bundle.min.js"></script>
<script src="js/main.js"></script>
```

Шрифты Unbounded (заголовки) и Manrope (текст) тоже подключены локально из папки `fonts/`. Сайт работает без интернета.

## Bootstrap-сетка

- `container` — основной контент, `container-fluid` — hero-блок на всю ширину;
- `row` + `col-12 col-md-6 col-lg-4` — карточки каталога (1 → 2 → 3 в ряд);
- `col-12 col-md-6 col-xl-3` — карточки залов (1 → 2 → 4 в ряд);
- `col-12 col-lg-8` + `col-12 col-lg-4` — форма записи и сводка;
- отступы между колонками — `g-2`, `g-3`, `g-4 g-lg-5`;
- utility-классы: `py-5`, `mb-4`, `d-flex`, `gap-*`, `align-items-*`, `text-body-secondary`, `rounded-4`, `shadow-sm`, `h-100` и др.

## Реализованные компоненты

Обязательные:

- `navbar` — единое меню на всех страницах, активный пункт, мобильное меню, выпадающий список `dropdown`;
- `card` — несколько вариантов: с изображением, ценовая, выделенная тёмная (`card-featured`), карточка события;
- `btn` — `btn-primary`, `btn-outline-primary`, `btn-dark`, `btn-outline-dark`, `btn-light`, размеры `btn-lg`/`btn-sm`;
- `badge` — метки услуг («Хит», «Новичкам», «−38%»), статусы мест и событий;
- `alert` — `alert-info`, `alert-warning`, `alert-success` с иконками;
- `modal` — «Быстрая запись» на всех страницах + «Правила посещения» на странице записи;
- `form-control`, `form-select`, `input-group`, `form-check` — формы записи, быстрой записи и обратной связи.

Дополнительные:

- `accordion` — FAQ, условия абонементов, правила зала, как добраться;
- `carousel` — отзывы на главной и галерея на странице вводного занятия;
- `nav-tabs` / `nav-pills` — программа занятия, переключение залов;
- `toast` — уведомление об успешной отправке формы;
- `tooltip` — подсказки к достижениям инструкторов;
- `breadcrumb`, `list-group`, `table`, `progress`, `btn-check`, `form-switch`, `nav-underline`.

## Самостоятельные доработки

1. **Локальное подключение Bootstrap** без CDN (`vendor/bootstrap/`), а также локальные иконки и шрифты.
2. **Расширенный набор страниц**: кроме обязательных четырёх добавлены `halls.html`, `kids.html`, `contacts.html`.
3. **Каталог с фильтрами**: фильтр по категориям (разовые, абонементы, тренировки, детям, события), сортировка по цене, счётчик найденного; выбранная категория сохраняется в адресе (`catalog.html?cat=kids`).
4. **Улучшенный сценарий записи**:
   - услуга подставляется из ссылки (`order.html?service=intro`) и из кнопки, открывшей модальное окно;
   - живой расчёт стоимости: цена × количество человек + прокат − скидка по промокоду `ЗАЦЕП10`;
   - если снаряжение входит в услугу, чекбоксы проката блокируются;
   - нельзя выбрать прошедшую дату;
   - валидация Bootstrap (`needs-validation`, `invalid-feedback`), после отправки — `toast`.
5. **Таблица трасс с фильтром** по залу и уровню сложности.
6. **Фирменный стиль** через CSS-переменные Bootstrap (`--bs-primary`, `--bs-btn-*`, `--bs-border-radius` и др.) — цвета кнопок, фокуса, вкладок и аккордеона переопределены без переписывания компонентов.
7. **Адаптивность**: проверено на ширине 375, 768, 1024 и 1440 px — нет горизонтальной прокрутки, таблицы обёрнуты в `table-responsive`, второстепенные колонки скрываются на малых экранах (`d-none d-md-table-cell`).
8. **Доступность**: ссылка «Перейти к содержимому», видимый фокус, `label` у всех полей, `aria-*` у вкладок, каруселей и модальных окон, `alt` у изображений, `role="alert"` у сообщений.
9. **Собственные иллюстрации** в формате SVG (стены с зацепами, логотип) — лёгкие и чёткие на любом экране.
10. **Светлая и тёмная тема** на встроенных цветовых режимах Bootstrap 5.3 (`data-bs-theme`): по умолчанию берётся системная настройка, выбор сохраняется в `localStorage`; фирменные цвета переопределены для `[data-bs-theme="dark"]`. Переключатель — в шапке и в настройках кабинета.
11. **Поиск по сайту**: кнопка в шапке или клавиша `/` (Ctrl+K) открывают `modal` с поиском по страницам, разделам, ценам и вопросам; совпадения подсвечиваются, работает навигация стрелками.
12. **Отзывы**: сводка рейтинга с распределением оценок (`progress`), карточки с фильтром по категориям (`nav-pills`), форма отзыва в `modal` с выбором оценки звёздами и валидацией; новый отзыв сразу появляется на странице и пересчитывает рейтинг.
13. **Частые вопросы**: 11 вопросов в `accordion`, поиск по ключевым словам с подсветкой и фильтр по темам (`btn-check`).
14. **Личный кабинет** (`account.html`): вход по имени и телефону, вкладки (`nav-pills` + `tab-content`) «Мои записи», «Абонемент», «История», «Настройки». Записи из формы на `order.html` автоматически попадают в кабинет, их можно отменить. Демо-версия: данные хранятся только в браузере.
15. **Анимации**: появление блоков при прокрутке, счётчики статистики, микроанимации при наведении; учитывается `prefers-reduced-motion`.

## Как проверить

1. Открыть `index.html` в браузере (или запустить локальный сервер: `python3 -m http.server` и открыть `http://localhost:8000`).
2. Проверить меню: переходы по страницам, активный пункт, выпадающий список «Детям и события», мобильное меню в DevTools.
3. `catalog.html` — переключить фильтры и сортировку, нажать «Записаться» на любой карточке: откроется модальное окно с выбранной услугой.
4. `product.html` — пролистать галерею, переключить вкладки, навести на бейджи инструкторов.
5. `order.html` — выбрать услугу, дату, количество человек, ввести промокод `ЗАЦЕП10`, отправить пустую форму (появятся ошибки) и заполненную (появится уведомление).
6. `halls.html` — переключить залы, отфильтровать таблицу трасс.
7. Проверить адаптивность в DevTools: 375, 768, 1024, 1440 px.
